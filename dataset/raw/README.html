We make our FAQ dataset for training a chatbot available only for ** academic activities **. If you use the dataset for any academic activities, you can modify it, for example adding new questions and/or answers. However, we don't any support for the custom. If you have any comments, please send an email to sumikawa-yasunobu [at] tmu.ac.jp (please replace [at] with @).

We attach an English version dataset translated from the Japanese dataset to ease understanding what contents our dataset has. Note here that we did not perform any evaluations including statistics analyses on the English version dataset; there are no results how accurate chatbots responds to questions.

首都大学東京のeラーニングシステムであるkibacoに特化したチャットボットを実現するために作成したFAQデータセットを公開しました。このデータセットは学術利用に限定し、新しい質問・回答の追加などの修正も含むめて利用することができます。しかし、大変申し訳ありませんが、この修正作業をお手伝いすることはできませんのでご了承ください。何かお気付きの点がございましたら、sumikawa-yasunobu [at] tmu.ac.jp （[at]を@に変更してください）までご連絡ください。

また、著者らによって翻訳した本データセットの英語版も公開しております。この英語版データセットも学術利用に限り、自由に利用することができますが、英語版データセットに関する実験は統計解析を含めて行っておりません。本研究で報告した実験結果は日本語版のみを用いており、英語版データセットでの結果に関して報告したものはありません。英語版データセットは参考までにご利用ください。
